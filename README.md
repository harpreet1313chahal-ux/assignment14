## Project Description

This project is a personal portfolio website built using React and TypeScript.

The website showcases my projects, technical skills, learning resources, and development environment while reusing components created in Assignment 13. React Router is used to navigate between multiple pages.

---

## Features

- Home (Basic Information)
- Work
- Skills
- Resources
- Developer Setup
- React Router navigation
- Reusable UI components from Assignment 13
- Responsive design
- Production Docker deployment

---

## Technologies Used

- React
- TypeScript
- React Router
- Styled Components
- Docker
- Git
- GitHub

---

## Install Dependencies

```bash
npm install
```

---

## Run the Application (Development)

```bash
npm start
```

The development server runs at:

```
http://localhost:3000
```

---

## Build the Project

```bash
npm run build
```

---

## Build the Docker Image

```bash
docker build -t harpreet_chahal_assignment14 .
```

---

## Run the Docker Container

```bash
docker run --name chahal_harpreet_coding_assignment14 -p 5575:5575 harpreet_chahal_assignment14
```

---

## Open the Application

```
http://localhost:5575
```
