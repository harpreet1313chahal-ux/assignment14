## Project Description

This project is a personal portfolio website built using React and TypeScript.

The website showcases my projects, technical skills, learning resources, and development environment while reusing components created in Assignment 13. React Router is used to navigate between multiple pages.

---

## Features

- Home page
- Work page
- Skills page
- Resources page
- Developer Setup page
- Navigation using React Router
- Reusable UI components from Assignment 13
- Responsive design
- Docker support

---

## Technologies Used

- React
- TypeScript
- React Router
- Styled Components
- Docker
- Git
- GitHub

---

## Install Dependencies

```bash
npm install
```

---

## Run the Application

```bash
npm start
```

The application will be available at:

```
http://localhost:3000
```

---

## Build the Project

```bash
npm run build
```

---

## Build Docker Image

```bash
docker build -t harpreet_chahal_assignment14 .
```

---

## Run Docker Container

```bash
docker run --name harpreet_chahal_assignment14 -p 8018:8018 harpreet_chahal_assignment14
```

---

## Open the Application

```
http://localhost:8018
```
